# Desktop Imposer Pro V3.0 开发路线图

## 阶段 0：基线恢复与审计

- [ ] 从 V2.2 源码包 + 补丁链恢复当前基线。
- [ ] 确认最终版本号、模块清单、依赖、构建脚本。
- [ ] 在 Windows CI 跑通 V2.4.x 现有测试和打包。
- [ ] 导出旧版功能矩阵、项目文件格式和 PDF 导出入口。
- [ ] 记录现有缺陷，建立 V3.0 回归样本。

验收：不改变功能的基线构建成功，旧版测试通过。

## 阶段 1：V3.0 工程骨架与统一模型

- [ ] 建立 domain/application/engines/ui/infrastructure 包边界。
- [ ] 定义毫米、point、像素的显式换算接口。
- [ ] 定义 Document/Page/Sheet/ImpositionJob/Mark 数据模型。
- [ ] 建立旧版工作区与 V3 模型的双向适配器。
- [ ] 建立单元测试与测试 PDF fixtures。

验收：V3 包可独立导入；模型序列化往返一致；不影响 V2.4.x 构建。

## 阶段 2：主界面与页面管理

- [ ] 左侧功能导航、中央画布、右侧属性面板、底部状态栏。
- [ ] PDF 批量导入、页面列表、缩略图、排序、旋转、排除。
- [ ] 画布缩放、平移、选择、拖拽和标尺。
- [ ] 任务进度、取消和错误提示。

验收：大于 100 页的测试 PDF 能流畅载入缩略图；UI 不因渲染卡死。

## 阶段 3：基础拼版引擎

- [ ] N-up 1/2/4/8/16。
- [ ] Step & Repeat。
- [ ] 纸张尺寸、成品尺寸、出血、边距、间距、咬口。
- [ ] 自动行列/方向优化。
- [ ] 裁切线、套准标、色条、页码、页面信息。
- [ ] PDF 矢量保留导出。

验收：页面数量、坐标、旋转、出血和标记位置全部通过 golden tests。

## 阶段 4：书刊与双面

- [ ] 骑马钉、胶装/书刊页序。
- [ ] 折手配置、签名、页数补白。
- [ ] 长边翻、短边翻、自翻版/天地翻。
- [ ] 爬移补偿和正反面预览。

验收：常见 8/16/32 页折手及双面测试样张通过人工核对和自动页序检查。

## 阶段 5：专业生产与模板

- [ ] 盒型/刀版排版和安全间距。
- [ ] 标签卷筒、卡牌、异形/异尺寸混拼。
- [ ] 嵌套与材料利用率优化。
- [ ] 拼版模板库、作业参数保存。
- [ ] 批量作业队列、热文件夹。

验收：每个模式都有独立测试样本和生产 PDF 输出验收表。

## 阶段 6：印前检查与发布

- [ ] PDF 页面框、出血、字体、图像分辨率等预检。
- [ ] 颜色空间、专色、透明度、叠印能力边界验证。
- [ ] 许可证、SBOM、安装包、便携版、SHA256。
- [ ] Windows 10/11 安装/卸载/升级测试。
- [ ] 发布说明、用户手册和故障日志导出。

验收：所有严重级别缺陷关闭；商业依赖许可完成核实；安装版和便携版均通过验收。
